# logicgatecalc

Animated logic gate calculator that shows:

1. Decimal input numbers.
2. Conversion to 8-bit binary.
3. Per-bit logic gate operation (AND/OR/XOR/NAND/NOR/XNOR).
4. Conversion of result back to decimal.

## Run locally

Open `index.html` directly in a browser, or serve the directory:

```bash
python -m http.server 8000
```
